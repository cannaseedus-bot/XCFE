# KGB-ZK-2 — Solidity Verifier (PLONK / Halo2)

This contract verifies **one constant-size proof** that may represent:

- many edge deltas
- many inference steps
- many brains (federated)
- recursively aggregated

It does **not** know anything about graphs, tensors, or prompts. It only enforces
**cryptographic validity + declared public inputs**.

---

## 1. Design Constraints (Locked)

We assume:

- Proof system: **PLONK over BN254** (Halo2-compatible)
- Curve: BN254 (Ethereum-native)
- Trusted setup: **none** (universal params off-chain)
- Public inputs:
  - `root_digest`
  - `policy_hash`
  - `lane_mask`
  - `max_depth`

Everything else is private.

## 3. BN254 Pairing Helpers

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

library BN254 {
    uint256 internal constant PRIME =
        21888242871839275222246405745257275088548364400416034343698204186575808495617;

    struct G1Point {
        uint256 x;
        uint256 y;
    }

    function negate(G1Point memory p) internal pure returns (G1Point memory) {
        if (p.x == 0 && p.y == 0) return G1Point(0, 0);
        return G1Point(p.x, PRIME - (p.y % PRIME));
    }

    function pairing(
        G1Point memory a1,
        G1Point memory a2,
        G1Point memory b1,
        G1Point memory b2
    ) internal view returns (bool) {
        uint256[12] memory input = [
            a1.x, a1.y,
            a2.x, a2.y,
            b1.x, b1.y,
            b2.x, b2.y,
            1, 0,
            1, 0
        ];
        bool success;
        assembly {
            success := staticcall(gas(), 8, input, 384, input, 0x20)
        }
        require(success, "pairing failed");
        return input[0] != 0;
    }
}
```

## 4. Verifier Contract (KGB-ZK-2)

```solidity
contract KGBZKVerifier is IKGBVerifier {
    using BN254 for BN254.G1Point;

    // Verification key hard-coded (generated by Halo2)
    BN254.G1Point constant vk_alpha =
        BN254.G1Point(
            0x1c3a...,
            0x2f91...
        );

    // Normally dozens of constants — abbreviated here
    BN254.G1Point constant vk_beta =
        BN254.G1Point(
            0x12ab...,
            0x0cde...
        );

    function verifyInference(
        bytes calldata proof,
        uint256[] calldata publicInputs
    ) external view override returns (bool) {
        require(publicInputs.length == 4, "invalid public input length");

        uint256 rootDigest = publicInputs[0];
        uint256 policyHash = publicInputs[1];
        uint256 laneMask = publicInputs[2];
        uint256 maxDepth = publicInputs[3];

        // Optional sanity checks
        require(maxDepth > 0 && maxDepth <= 1024, "invalid depth");

        // Decode proof (Halo2 layout)
        (
            BN254.G1Point memory A,
            BN254.G1Point memory B,
            BN254.G1Point memory C
        ) = _decodeProof(proof);

        // Pairing check (PLONK equation)
        return BN254.pairing(
            BN254.negate(A),
            vk_alpha,
            B,
            vk_beta
        );
    }

    function _decodeProof(
        bytes calldata proof
    )
        internal
        pure
        returns (
            BN254.G1Point memory A,
            BN254.G1Point memory B,
            BN254.G1Point memory C
        )
    {
        require(proof.length >= 192, "proof too short");

        assembly {
            A.x := calldataload(proof.offset)
            A.y := calldataload(add(proof.offset, 32))
            B.x := calldataload(add(proof.offset, 64))
            B.y := calldataload(add(proof.offset, 96))
            C.x := calldataload(add(proof.offset, 128))
            C.y := calldataload(add(proof.offset, 160))
        }
    }
}
```

> In production, this is generated automatically by Halo2 tooling.
